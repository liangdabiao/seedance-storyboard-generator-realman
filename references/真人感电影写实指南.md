# 真人感电影写实指南

生成 Seedance 提示词时「怎样才像真的」的单一事实来源。SKILL.md 的写法以此为准。

**可信度分级**（不把自造规则当硬约束）：【案例】=提炼自用户提供的优秀提示语实测案例，可作依据；【用户要求】=用户明确要求，硬规则；【编排建议】=落地模板，可随项目调整。下文只标结论，不逐条抄案例原句（原句见 `example/`）。

---

## §1 真人感的六根支柱

「真人感」靠以下六个**可被看见/听见**的维度写实，不靠"电影级/4K/高级感"这类空话。凡不能落地的形容词等于没写。

| 支柱 | 怎么写 |
|---|---|
| 摄影介质 | 具体胶片/颗粒/光位：35 毫米胶片观感、细腻颗粒、柔和高光、手持呼吸感、自然运动模糊 |
| 皮肤与材质 | 不完美细节：汗水、毛孔、细小瑕疵、碎发、老年斑、织物磨损、金属划痕泥点 |
| 空间锚定 | 具体数字 + 左右站位 + 相互距离（一步/三米/半米），体型差用身体部位或倍数做参照 |
| 物理因果 | 发力 → 接触 → 受力反馈 → 惯性余韵，四环齐全不省略接触；快动作也要有接触受力 |
| 呼吸与微表情 | 用生理变化写情绪：呼吸、眼神、嘴角、肩膀、嘴唇颤动，不写"很悲伤/很震惊" |
| 同期声与口型 | 台词写在说话那一刻 + 嘴部可见 + 口型同步；动作音贴接触点 |

> 落法：支柱融进流畅叙述，不贴标签（见 §2）。资产图同样要有皮肤/毛发/衣料细节，中性表情只用于锁形象，不进视频提示词。

## §2 弧线与结构：写成小说，不写成检查表

**这是压倒性的最高原则（血泪教训）**：曾把弧线/轴线/因果/机位理由当成要逐条贴进每段的标签，写成施工检查表，成片被评"死板、愚蠢、笨拙"。视频 AI 是聪明的，啰嗦标签只会让它混乱。优秀案例读起来是一段**电影小说**——所有结构要素都在，但没有一个术语。

写作时**内化**以下八点，用短句自然写出，写完通读删掉一切标签/重复/空话：

1. **弧线**：开头一句"从…到…最后…"定脊柱，各段都服务它。
2. **空间可通行**：写清站位/距离/朝向/相互留空（不贴"负空间声明"），漏了模型会塞进路人家具。
3. **正向锁定**：跨镜维持项写成"全程用同一把剑/此后连续拍摄"，不写"禁止换剑"。
4. **机位与理由**：景别 + 一句目的（避开动作路径/容纳接触点），化进句子，不贴"机位理由:"。
5. **段内时序**：完整动作用"前一秒/随后两秒/最后一秒"分开写先后。
6. **段间承接**：每段首句接住上段结束的具体状态，防重演。
7. **声音动态**：随画面此消彼长，一整段散文（见 §4）。
8. **收尾运镜**：从什么景别起、往哪运、几秒完成、先缓后快再减速、停在哪——不用"切空镜"了事。

## §3 时间轴

- 时段精确到 0.1 秒：`[00.0-03.0s]`、`[03.0-05.5s]`，不用"0-3秒"。
- 一段一镜一动作；相邻段至少变一项（景别/角度/主体尺度/明暗/运动方向）。
- 需要完整呈现因果的段明写"保持连续拍摄/不切镜"，不通过切镜省略接触和受力。
- 切镜类型：对话用自然直切/视线匹配；连续动作换视点用动作匹配切；也可用形状匹配切。

---

## §4 对白、口型与声音

**4.1 台词写一次（血案红线）**：Seedance 原生生成语音口型。台词逐字写在角色说话那一刻（"他压着火说：'上帝不掷骰子！'"），说话镜头写明嘴部清晰可见；【声音】段只统一声明"同期声、口型同步、声线清晰、不抢话"，**不再罗列台词**。只写"生成音效"会导致成片全哑——付出过代价，绝不能犯。

**4.2 声音是一整段动态线**：开场突出近处声（呼吸、握剑摩擦、衣甲轻响）→ 动作时接触音贴画面（击中、落地、碎裂）→ 收尾远景声渐展开、近处声减弱、跨镜头衔接。对白在前、配乐第二、环境动作第三，写进句子不列成表。

**4.3 配乐按题材自主判断**（不问用户，别一律无配乐）：

| 片子类型 | 配乐 |
|---|---|
| 对白/表演主导的写实生活流 | 极轻钢琴点缀，或完全无配乐 |
| 动作/打击主导 | 通常无配乐，让接触音与呼吸成节奏 |
| 情绪弧线/长叙事 | 明确配乐，跨镜连续发展，不每次切镜重起 |
| 广告/片头/卡点 | 明确节拍与配器，音效让位于关键拍点 |

写清乐器/进入时机/随情绪发展/结尾收束/音量低于对白。描述进入时机用指代（"从他反将一军那一刻"），别抄台词原文。结尾统一写无旁白、无字幕、无水印。

## §5 各题材质感

真人感是主线，用户点名其他风格时按此调整首行与质感词：

| 题材 | 质感落点 |
|---|---|
| 写实剧情/战争/西部 | 胶片颗粒、皮肤瑕疵、低饱和、自然速度、手持呼吸感 |
| 真人奇幻/冒险 | 上述 + 重量感：布料回摆、接触受力、翼膜承风 |
| 真人广告/微距 | 材质光学（透射/折射/拉丝/哑光）、浅景深、实体前景遮挡 |
| 二维手绘动画 | 真实感来自运动规律与空间比例，不是皮肤纹理；纸面颗粒、平涂、关键姿势 |
| 精细二维/赛璐璐动作 | 打击受力、脚底支撑、动作连续不省略；快动作允许短拖影 |
| 国风仙侠动画 | 特效有能量来源与阶段，法相有独立空间位置，不挡面孔 |
| 动态漫画/平面 | 文字与版面稳定，节奏由重拍与图形切换驱动 |
| 白模转视频 | 第一帧即完成材质，材质分配逐物体写明 |
