> **本文件的定位**：这是本 skill 生成 Seedance 提示词时，关于「怎样才像真的」的**单一事实来源**。
> 本 skill 只有一个参考文件，就是本文件；SKILL.md 的 5.1 分镜模板与质量自检清单中的相关写法，一律以本文件为准。
>
> **来源与可信度分级**（遵守「不把自造规则包装成硬约束」）：
> - 【案例】= 提炼自用户提供的 `D:/seedance-video-test/参考提示语.txt` 中的完整实测案例，每条注明案例名。这是**有实测依据**的做法，可作为规则。
> - 【用户要求】= 用户明确要求过的做法（如台词逐字写入【声音】段）。这是**硬规则**。
> - 【编排建议】= 为了把上述做法落地而设计的模板/流程，**不是硬约束**，可按项目实际情况调整。

## §1 真人感的六根支柱

「真人感」不是一个形容词，而是六个可以逐条写进提示词的技术维度。参考案例之所以像真的，是因为它们把每一维都写实了。

| 支柱 | 案例里怎么写（摘录） | 在提示词中的落点 | 来源 |
|---|---|---|---|
| **1. 摄影介质** | "35毫米胶片摄影观感，细腻颗粒、柔和高光、适度对比、真实空气透视"（骑龙）；"轻微手持呼吸感，自然运动模糊"（骑士战场） | 首行风格块 + 每个镜头段内的光线说明 | 【案例】骑龙/骑士战场/海边对白 |
| **2. 皮肤与材质** | "皮肤可见汗水、灰尘和细小瑕疵，钢甲有划痕、凹痕与潮湿泥点"（骑士战场）；"保留真实毛孔和奔跑后的微红"（骑龙）；"面部细节不油腻，雀斑、碎发和衣料的纹理细腻"（海边对白） | 首行风格块 + 人物资产提示词 + 特写段 | 【案例】骑士战场/骑龙/海边对白/口红广告 |
| **3. 空间锚定** | "距离盾阵前沿只有一步"；"正前方约三米处"；"两人相距半米"（海边对白）；"大门到主桌A约三米"（客栈调度） | 人物与空间段，用**具体数字**写距离、体型、比例 | 【案例】骑士战场/海边对白/客栈调度/怪兽拔刺 |
| **4. 物理因果** | "右脚蹬地，重心移向前方左腿，双手带剑完成一次有重量的斜斩"（骑士战场）；"每次命中都立即出现衣料压缩、身体偏转、失衡或脚底位移，受力方向与拳脚方向一致"（高速打斗） | 动作段写成「发力→接触→受力反馈→惯性余韵」的链条 | 【案例】骑士战场/高速打斗/骑龙/猫咪南瓜饼 |
| **5. 呼吸与微表情** | "短促吸气，嘴唇微张，剑柄在画面下缘轻轻颤动，眼神由紧张变得专注坚定"（骑士战场）；"缓慢吐出一口长气，眉心逐渐舒展，嘴角浮现很浅的笑意"（海边对白） | 每个情绪段落写**生理性动作**，不写抽象情绪词 | 【案例】骑士战场/海边对白/生日男孩/老人与马 |
| **6. 同期声与口型** | "对白时让说话者的嘴部清晰可见，口型与台词同步"（海边对白）；"所有动作音与接触和发力同步"（骑龙） | 【声音】段逐字写台词，动作音严格对齐接触点 | 【案例】海边对白/生日男孩/西部情书/白模转视频 +【用户要求】 |

**关键认知**：参考案例里没有一个用"电影级、4K超清、高级感、氛围感拉满"这类空泛形容词来制造真实感。它们靠的是**具体**——具体的胶片、具体的瑕疵、具体的厘米/米、具体的发力点、具体的呼吸、具体的声音。写提示词时，凡是不能在成片里被看见或听见的词，都等于没写。

## §2 首行风格块（写实真人版）

### 2.1 配方

【案例】各真人题材案例的首行/风格段，共同包含以下成分（顺序可微调）：

```
一段[时长]的[题材]短片，[画幅]，[摄影介质 + 胶片/颗粒特征]，
[具体色名清单（低饱和）+ 光位与光线质感]，
[皮肤与材质的不完美细节]，[运动特征（运动模糊/手持呼吸感/自然速度）]，[本集氛围]
```

### 2.2 模板（【编排建议】，逐集逐字相同，只换末尾氛围词）

```
生成一段15秒的[题材]短片，[16:9横屏 / 9:16竖屏]，真人实拍质感，35毫米胶片摄影观感，
细腻胶片颗粒，柔和高光，克制的高光与适度对比，保留真实空气透视；
色彩为低饱和的[具体色名1]、[具体色名2]与[具体色名3]，[光位描述，如：柔和天光从画面左上方照来，暗部深沉且保留细节]；
皮肤可见[汗水/细小瑕疵/毛孔/短暂泛红]，[衣料/金属/木材/石材]保留自然纹理与磨损；
自然速度，近景有轻微手持呼吸感，快速动作带合理电影快门拖影；
避免过度磨皮、过饱和、炫光、塑料皮肤与游戏过场动画质感。[本集氛围]
```

### 2.3 首行纪律

- 【案例】风格描述在参考案例里出现在首行，并在【整体视觉】等段落中再次强化——长正文会稀释首行，所以**每段至少自然带回一个质感词**（如"胶片颗粒""真实皮肤纹理""低饱和"）。来源：骑士战场/骑龙/海边对白。
- 【编排建议】同一剧集每集首行**逐字相同**，只替换末尾氛围词，防止跨集风格漂移。

### 2.4 反面词表（【案例】明确点名避免）

参考案例中出现过的"禁止"表述，可直接引用：

> 避免过度磨皮、过饱和与炫光；避免塑料皮肤、镜面鳞片、过度锐化、夸张橙青滤镜和游戏过场动画质感；不要突然切换成明显笑脸；避免夸张哭泣与戏剧化动作；不出现喷血或肢体分离；不使用突然跳升或高速穿梭；无字幕、片名、文字、Logo、水印。

来源：海边对白 / 骑龙 / 骑士战场 / 怪兽拔刺 / 街机。

## §3 时间轴写法规范

### 3.1 格式（【案例】）

参考案例的时段标记统一为**精确到 0.1 秒**的方括号格式：

```
[00.0-03.0s]
[03.0-05.5s]
[05.5-10.0s]
```

不是 `0-3秒`、`3-7秒` 这种粗粒度占位。参照：骑士战场/海边对白/骑龙/老人与马/口红广告/怪兽拔刺/西部情书。

### 3.2 一段一镜一动作（【案例】）

- "每个时间段只呈现该段指定的一种取景画面"（老人与马）。
- "每个镜头只完成一个明确动作，镜头之间用颜色、线条和光的方向衔接"（口红广告）。
- "全片按……组织，每次切镜必须改变至少一项：景别、观察角度、主体尺度、画面明暗占比或运动方向"（单色片头）。
- "越栏与龙背承接之间不插入特写或空镜，不通过切镜省略下落、接触和缓冲"（骑龙）。

**落法**：每个时段开头先写**机位与景别**，再写**人物的姿态与微动作**，再写**物理动作链**，最后写**该段的声音钩子**。切镜方式要明写：

| 切镜类型 | 案例原句 | 用法 |
|---|---|---|
| 自然直切 | "使用五个明确镜头……以自然剪辑、视线匹配形成节奏"（海边对白） | 对话段落，配合说话/倾听切换 |
| 动作匹配切 | "在女孩抬头时动作匹配切至40毫米侧前方中景"（骑龙） | 连续动作中换视点，不省略动作 |
| 形状匹配切 | "斜边匹配切到侧面中景"（单色片头） | 用画面中已有形状做转场 |
| 不切镜 | "此后至片尾保持连续拍摄"（骑士战场）；"前10秒维持同一固定镜头"（老人与马） | 需要完整呈现动作因果或时间流逝时 |

### 3.3 每段四要素模板（【编排建议】）

```
[00.0-03.0s]
镜头[序号]，[焦段/机位]，[景别]，[构图与画面内元素位置]。
[人物起始姿态与生理性微动作：呼吸、视线、嘴唇、肩膀、手部]。
[物理动作链：发力点 → 接触点 → 受力反馈 → 惯性余韵，动作在几秒内完成]。
[该段声音钩子：动作音与接触点同步 / 台词 / 环境声的变化]。
```

## §4 空间锚定与 180 度轴线

### 4.1 用数字和相对位置锁死空间（【案例】）

- "男孩正前方约三米处有一只……小怪"；"男孩站在己方盾阵预先留出的狭窄通道内，距离盾阵前沿只有一步"（骑士战场）。
- "两人相距半米，站在宽阔、平稳的草坡上"（海边对白）。
- "摄影师穿……站在老人正前方约两米处"（老人与马）。
- "主桌A是画面前侧中央的大方木桌……大门到主桌A约三米"（客栈调度）。

**落法**：人物段必须写出「谁在画面左/右」「面向哪一侧」「相互距离」「与关键道具/家具的距离」。不要只写"A 和 B 在聊天"。

### 4.2 180 度轴线与视线匹配（【案例】）

海边对白的原句，可直接作为对话场景的写法范本：

> "摄影机保持人物眼睛高度，所有对话机位位于两人连线的同一侧，遵守180度轴线。A看向画面右侧的B，B看向画面左侧的A，切镜后视线方向准确衔接。"
> "过肩镜头中，前景只保留倾听者少量虚化肩部与后脑轮廓，占画面边缘约15%，说话者的脸完整清晰，双眼与嘴唇均可见。"

怪兽拔刺同样："镜头统一遵守男孩与怪兽之间的动作轴线，摄影机始终位于轴线朝向观众的一侧。男孩保持在左侧，怪兽保持在右侧，近景也沿用相同的动作方向。"

**落法**：多角色/对话场景，在【摄影】或【人物与空间】段写明轴线；在【连续性】段写"禁止越轴"。

### 4.3 形体比例（【案例】）

- 怪兽拔刺："它坐下后，从地面到头顶的高度约为男孩身高的三倍；一只后脚的长度接近男孩的身高，鼻头约有男孩半个身子宽。"
- 街机："男孩约八岁，站在地面时头顶约到女玩家腰部，全身约三头身。"

**落法**：涉及体型差时，用人物之间的倍数/身体部位做参照，不写"非常巨大"。

## §5 动作物理因果链

### 5.1 四个环节（【案例】）

参考案例的关键动作都不是"他打了他"这种结果式描述，而是完整链条：

```
发力点：右脚蹬地，重心移向前方左腿        （骑士战场）
接触点：长剑击中它肩胸处的皮甲            （骑士战场）
受力反馈：短刀脱手，身体侧倒，泥水溅开      （骑士战场）
惯性余韵：剑尖停在自己左前方低处，右脚跟进小半步，稳住身体（骑士战场）
```

骑龙案例的落鞍："接触瞬间，皮鞍受压，固定皮带绷紧，女孩肩膀和长辫产生轻微惯性颠动；巨龙身体顺势下沉少许，再通过翼面承托稳定住重心。"

高速打斗的全局约束："每次命中都立即出现衣料压缩、身体偏转、失衡或脚底位移，受力方向与拳脚方向一致。"

### 5.2 速度由内容决定，不由"稳"决定

- 【案例】骑士战场："全段保持正常速度，仅有一次斩击。剑刃击中、怪物失衡、身体落地和男孩站稳依次完成。"
- 【案例】高速打斗：整段是"连续爆发的极速近身拳脚交换"，每 2 秒完成进攻、防守、反击，"没有蓄势、停顿、对视、慢动作、变速、定格或收势展示"。
- 【案例】单色片头："紧凑感来自镜头长度、快速构图变化、遮挡与节拍，不将人物整体倍速播放。"

**结论**：真人感 ≠ 一律慢动作。该快就快，但**快动作也不能省略接触和受力**。"动作一律写慢"只适用于手绘动画等特定质感，不适用于写实真人动作戏；各题材的质感取向见本指南 §8。

### 5.3 禁止清单（【案例】直接引用）

> 禁止长时间悬空、瞬移、肢体穿过栏杆、裙摆穿入龙身、手指与鞍桥融合、巨龙突然缩放、翅膀穿墙和无发力垂直升空。（骑龙）
> 禁止穿墙、穿墩、穿地、瞬移、悬浮、身体互穿、无接触受击、分身、换脸、服装互串、动作重播和场景重置。（高速打斗）
> 脚掌踩实才蹬地，身体腾空必须有明确受力来源，落地后接下一步。（高速打斗）

## §6 对白、口型与声音

### 6.1 台词逐字写入（【用户要求】+【案例】）

Seedance 2.0 原生生成对白语音与口型，**台词必须逐字写进提示词的【声音】段**，画面该拍的段要写"开口说话/轻声说/脱口道"。这是已验证的硬规则。

参考案例的写法（海边对白），可直接套用：

```
[02.0-05.8s]
镜头二：越过B肩膀拍摄A的近景。……A的面容位于画面偏左，接近正面，双眼和嘴部清晰可见。
A先看着B，嘴唇轻轻分开，吸一口气，以轻而略带疲惫的成年女性声线缓慢说出：
女性A：“I wish I'd said goodbye.”
使用自然、柔和的标准英式英语发音，带一点气息感。"goodbye"尾音轻轻落下……
整句对白在这个镜头内说完，嘴唇动作与每个词同步。摄影机保持稳定，留出句末短暂停顿。
```

包含要素：**说话人 + 语气/声线 + 语言或发音 + 逐字台词 + 口型同步要求 + 说话时机（在哪个镜头说完）**。

中文案例（怪兽拔刺）同样逐字："男孩稍稍抬头，轻声说：'别怕，我帮你。'"；"怪兽用低沉、温厚的声音说：'谢谢你，小家伙。'"

【声音】段汇总写法（海边对白）："全片只有上述两句英文对白，分别由对应女性说出，声线清晰可辨，口型与台词同步，不抢话，不重复台词，不添加旁白。A说话时B安静倾听……"

### 6.2 声音三层（【案例】）

| 层 | 内容 | 案例原句 |
|---|---|---|
| 前 | 对白 / 朗读 | "女声为最前方的声音"（西部情书） |
| 中 | 配乐（如有） | "配乐为始终可辨认的第二层……朗读期间适度压低配乐，但仍能听清小提琴主题"（西部情书） |
| 后 | 环境与动作音 | "风声、马蹄、纸张与篝火为第三层"（西部情书）；"所有动作音与接触和发力同步，声音随距离自然变化"（骑龙） |

### 6.3 配乐由生成时按题材自主决定（【案例】）

**不设默认值，也不问用户**：写提示词时按下面四类判断，用户不点名也照样按题材给出最合适的配乐方案。用户明确要求时以用户为准。

判断框架（全部来自参考案例的实际做法，不是自创规则）：

| 片子类型 | 配乐处理 | 案例依据 |
|---|---|---|
| 对白/表演主导的写实生活流 | 极轻的钢琴点缀，或完全无配乐 | 海边对白："极轻的毡音钢琴……音量低于对白"；生日男孩、老人与马明确"无配乐" |
| 动作/打击主导 | 通常无配乐，让接触音与呼吸成为节奏 | 高速打斗"无背景音乐"；客栈调度"无背景音乐"；骑龙保留警钟/龙鸣/振翼/海浪 |
| 情绪弧线/长叙事需要音乐牵引 | 明确配乐，且跨镜头连续发展，不每次切镜重起 | 西部情书整段原创管弦乐；怪兽拔刺"少量低音木管与清亮拨弦"；九尾狐东方仙侠管弦乐 |
| 节奏驱动的广告、片头、卡点 | 必须有明确节拍与配器，且音效让位于关键拍点 | 口红广告时装电子节拍；动态漫画 180 BPM 碎拍；单色片头 120 BPM 原创器乐；白模转视频悬疑片头 |

**写【声音】段时明确三件事**：有什么声、谁在前、有没有配乐。有配乐时再写明：乐器/风格、进入时机、随情绪如何发展、结尾如何收束，以及音量与对白/动作音的层次关系（案例中配乐通常低于对白与关键动作音）。

### 6.4 哑剧风险（【用户要求】）

只写"只生成音效"、不写台词，会导致成片人物不开口、口型不对——这是已经付出过代价的错误。**有台词的段落，必须在【声音】段逐字写出台词，并在对应镜头段写出人物开口说话的动作。**

## §7 连续性段（【案例】）

参考案例几乎都以独立的【连续性】/【声音与连续性】/【全局连续性】段收尾。这是防漂移的关键，不是可选项。

### 7.1 两段式模板（【编排建议】）

```
【连续性】
一致清单：
- 人物：面孔、发型、服装、握持方式、站位左右关系全程一致。
- 道具/场景：形状、数量、位置、材质、状态（点燃/展开/缺口）在指定时刻保持不变。
- 光线/运动：光向、主运动方向、透视关系、景别与观察侧别按段锁定。
禁止清单：
- 禁止[从对应案例中摘取具体的崩坏项，如：瞬移、换脸、服装互串、越轴、形状变化、悬空……]。
```

### 7.2 案例里的写法

- 猫咪南瓜饼："从模具抬起、南瓜饼脱模开始，到入锅、煎制……始终保持模具确定的六瓣花形。所有镜头中的成品统一使用同一种花形，花瓣数量、凹口、厚度与花纹结构连续一致。"
- 西部情书："女人在开场与结尾保持同一张脸、发型、衣裙、信纸、站位与持纸高度，窗光方向一致。"
- 客栈调度："保持固定两张餐桌和一处柜台，同一批人物沿可见地面移动。脸、衣装、兵器归属与手部握法贯穿一致。"

**落法**：一致性要写成**可核对的属性清单**，禁止项要写成**该片具体可能崩的项**，不要套"人物不变形"这种通用话。

## §8 各题材的质感取向（【案例】）

真人感是主线，但不同题材的"真实"落点不同。用户点名其他风格时，按下列取向调整首行与质感词：

| 题材 | 质感落点 | 参考案例 |
|---|---|---|
| 真人写实剧情/战争/西部 | 胶片颗粒、皮肤瑕疵、低饱和、自然速度、手持呼吸感 | 骑士战场/海边对白/西部情书 |
| 真人奇幻/冒险 | 在上述基础上加"重量感"：布料回摆、接触受力、翼膜承风 | 骑龙 |
| 真人广告/微距 | 材质光学特性（透射/折射/拉丝/哑光）、浅景深、实体前景遮挡 | 口红广告 |
| 二维手绘动画 | 真实感来自**运动规律与空间比例**，不是皮肤纹理；保留纸面颗粒、平涂、关键姿势 | 怪兽拔刺/单色片头 |
| 精细二维/赛璐璐动作 | 打击受力、脚底支撑、动作连续不省略；快速动作允许短拖影 | 高速打斗/街机 |
| 国风仙侠动画 | 特效有明确的能量来源与阶段，法相有独立空间位置，不遮挡面孔 | 九尾狐 |
| 动态漫画/平面设计 | 文字拼写与版面结构稳定，节奏由重拍与图形切换驱动 | 动态漫画 |
| 白模转视频 | 第一帧就是完成材质，禁止先白模后上色；材质分配逐物体写明 | 白模转视频 |

## §9 平台合规与真人感的取舍（【编排建议】）

skill 的旧版本保留了"真人审核限制解决方案"（局部面部转绘、脸部加网格、遮挡等）。这些做法与"突出真人感"的目标**天然冲突**——网格或转绘会破坏皮肤真实感。

- 这些手段定位为**平台拒审时的兜底**，不是默认流程，不在提示词模板中主动加入。
- 用户明确要求时才启用，并告知代价：画面会出现网格/转绘痕迹，真人感下降。
- 生成类项目优先通过"虚构角色设定"规避（参考案例常用写法："人物为虚构角色，采用自然实拍质感"，见老人与马案例）。来源：【案例】老人与马。

## §10 落地检查（写提示词时逐条问）

- [ ] 首行有没有写明摄影介质、胶片/颗粒、具体色名、光位，而不是"电影级/高级感"？
- [ ] 人物有没有具体年龄、脸型、皮肤/毛发/衣料的不完美细节？
- [ ] 空间有没有数字（距离/比例/左右位置）？对话有没有写轴线与视线衔接？
- [ ] 每个动作有没有"发力→接触→受力→惯性"，而不是只有结果？
- [ ] 情绪有没有写成呼吸、眼神、嘴角、肩膀的生理变化，而不是"很悲伤/很震惊"？
- [ ] 台词有没有逐字写进【声音】段？说话镜头有没有写"嘴部清晰可见 + 口型同步"？
- [ ] 时间轴是不是 `[00.0-03.0s]` 这种精度？每段是不是只有一个机位、一个主要动作？
- [ ] 有没有独立的【连续性】段，且一致清单和禁止清单是针对本片具体内容的？
- [ ] 有没有把"无字幕、无片名、无 Logo、无水印"写进结尾？
