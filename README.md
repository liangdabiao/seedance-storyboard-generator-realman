# Seedance 真人感分镜生成器（Realman）

一个帮你把**故事/剧本**变成**真人实拍质感 AI 视频**的技能包。

简单说：你给它一个故事，它帮你走完从剧本到成片的全过程，而且生成的画面尽量像真人拍的电影，而不是卡通、动画或塑料感的游戏画面。

---

## 它能帮你做什么？

- 把一篇文章、小说、故事大纲改写成**短剧剧本**（分集、台词、镜头）
- 为角色、场景、道具写**生图提示词**，先做出参考图锁定形象
- 按**真人感六根支柱**写 Seedance 视频提示词（精确时间轴、逐字对白、口型同步、连续性约束）
- 规划整部剧的制作流程：**文 → 资 → 视 → 剪**

它默认追求**真人实拍质感 + 电影感**，这是它和一般分镜工具最大的不同。

---

## 核心特点：真人感六根支柱

普通提示词容易写出"电影级、高级感"这种空话，模型看完还是出卡通脸。这个技能把"真人感"拆成 6 个能直接写进提示词的具体维度：

| 支柱 | 意思 | 举例 |
|---|---|---|
| 摄影介质 | 写具体胶片、颗粒、光位，不写空泛形容词 | "35 毫米胶片、细腻颗粒、壁炉暖橙光＋窗外冷蓝夜光" |
| 皮肤与材质 | 写不完美的小细节 | "毛孔、细小皱纹、碎发、衣料磨损" |
| 空间锚定 | 写具体距离和站位 | "两人相距约三米，爱因斯坦在左、玻尔在右，180 度轴线" |
| 物理因果 | 动作要有发力和受力，不许瞬移 | "手腕发力→粉笔掷出→撞上黑板断裂→粉末落下" |
| 呼吸微表情 | 用生理变化代替抽象情绪词 | "嘴唇微张、短促吸气、肩膀绷紧"（而不是"他很愤怒"） |
| 同期声口型 | 台词逐字写进【声音】段 | "「这个理论，我不接受。」+ 口型与每个词同步" |

这些规则的详细出处和模板，都在 `references/真人感电影写实指南.md`（本技能的**唯一事实来源**）。

## 怎么用？

### 第一步：准备环境

生成视频和图片用的是**即梦 CLI**（`dreamina-canvas`），需要先安装并登录：

- 官网：https://jimeng.jianying.com
- 装好后用 `dreamina-canvas auth status` 确认登录成功

> 不装这个也能用本技能写剧本和提示词，只是不能实际生成图片/视频。

### 第二步：给技能一个故事

你可以直接说：

> "写一个爱因斯坦和玻尔在室内争论的故事，做成短剧。"

技能会按下面四步走（**文-资-视-剪**）：

| 阶段 | 做什么 | 产出 |
|---|---|---|
| **文** | 把故事写成剧本、分集 | `XX_剧本.md` |
| **资** | 给角色/场景/道具写生图提示词，做出参考图 | `资产提示词.md` + 一堆资产图 |
| **视** | 用参考图写视频提示词，生成视频片段 | `E0X_Seedance提示词.md` + 视频 |
| **剪** | 把片段拼成成片 | 成片 mp4 |

**关键顺序**：一定要先出资产图（资），再用它当参考生成视频（视）。跳过"资"会导致每集人物换脸、场景漂移。

### 第三步：生成前会先报预算

生成图片和视频要花即梦积分。技能会先用免费报价接口算出这一批要花多少，报给你确认后再跑，不会偷偷刷卡。

## 默认配置（用户可覆盖）

| 项目 | 默认值 |
|---|---|
| 生图模型 | Seedream 5.5 |
| 生视频模型 | Seedance 2.5 Flash |
| 视频分辨率 | **480p**（15 秒约 105 积分；720p 约 285 积分） |
| 画幅 | 按题材定（室内双人对话用 16:9，短视频用 9:16） |
| 配乐 | 不设默认，按题材由技能自己判断 |

用户点名要别的模型/分辨率/风格时，以用户为准。
